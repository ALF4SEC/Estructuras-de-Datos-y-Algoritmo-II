# Árboles binarios

Implementación de un árbol binario genérico en C: recorridos (preorden, inorden, postorden y amplitud), funciones recursivas sobre el árbol y construcción de un árbol de expresión a partir de una expresión postfija.

```bash
make ejercicio1   # recorridos
make ejercicio3   # árbol de expresión
```

El resto de temas de la asignatura están descritos en el [README principal](../README.md).
